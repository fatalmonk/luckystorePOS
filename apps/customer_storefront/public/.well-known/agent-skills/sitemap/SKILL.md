# Sitemap Skill

## Description
XML sitemap listing all canonical product and category URLs for luckystore1947.com.

## Location
`https://luckystore1947.com/sitemap.xml`

## Format
Standard XML sitemap protocol (https://www.sitemaps.org/protocol.html).

## URLs Included
- Homepage (`/`)
- Category pages (`/category/{slug}`)
- Product pages (`/product/{id}`)
- Search page (`/search`)

## Update Frequency
Regenerated on each deployment with current product catalog from Supabase.
